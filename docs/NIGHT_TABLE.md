# جدول طراحی ۳۶ شب — نسخهٔ ۴۴

## ردیف واکنشی حین موج (بانک مشترک، ضدتکرار)
شرط‌های اجرا: جونِ برج < ۳۰٪ · خاموشی فعال · ورود باس · کمبو ≥ ۱۵ · منابع < ۲۰ · دشمنِ مسیرِ دوم · منجمد/سوختان.
هر شرط ۳ تا ۵ خط متنوع؛ انتخاب با چرخش `lastUsed`؛ هیچ خطی دو موجِ پیوسته تکرار نمی‌شود.
