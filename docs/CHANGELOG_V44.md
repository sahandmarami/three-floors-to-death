## ۴) پایانِ سه‌گانه + Cliffhanger (`scripts/v43_ending.js` بازنویسی‌شده + `v44_ending.js`)
- زنجیرهٔ نهایی: `arrive→welcome→siren→control→escape→fire→part→console→choice→(endOff|endRedirect|endBroadcast)→anonmsg→creditroll`
- **UI انتخابِ سه‌گانه** (سه کارت با توضیحِ هزینه‌ها؛ زمان متوقف؛ انتخاب در Save ثبت می‌شود)
- سه صحنهٔ اختصاصی: خاموشی (تاریکیِ مانیتورها + چراغ قرمز) / انحراف (نقشه با مسیر به دشتِ نمک) / پخش (آنتنِ موج‌زا + صف مانیتورها)
- **پیام ناشناس** («ازش بپرس چه کسی مختصات برجِ سه‌طبقه رو براش فرستاد») → سکوت ارشان → «یه چیزی هست که باید از همون اول بهت می‌گفتم...» → سیاهی
- صفحهٔ پایانی: **«پایان فصل اول داستان — ادامه دارد...»** + کارنامهٔ نبرد
- قانون ۶۴ (دیالوگِ معلق): هر گذارِ فاز `DLG.skip()+VOICE.stop()` دارد و capهای فاز با طول دیالوگ تنظیم شد
