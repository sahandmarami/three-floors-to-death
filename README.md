# سه طبقه تا مرگ (Three Floors to Death)

بازی ماجرایی–دفاعی فارسی برای مرورگر و اندروید — همه‌ی بازی در **یک فایل HTML** (بدون سرور، بدون وابستگی).

**نسخه‌ی ۴۳٫۰ — بازسازی کامل سینمایی پایان + پلتفرمر ماریوئی:**

- **سینمایی پایان از صفر ساخته شد (ویدیوی کدنویسی‌شده):** دیگر سیاه‌وسفیدِ خالی نیست — کاراکترهای واقعی با صورت، مو، لباس و انیمیشن (آرش با کاپشن سرمه‌ای، ارشان با سربند سرخ، دکتر مریم با روپوش سفید و روسری سبز، دکتر سارا با باند، نگهبان با کلاه‌خود و چراغ‌قوه) در ۱۲ صحنهٔ سینمایی: دروازهٔ پناهگاه با برجک‌ها و جستجوگر، حیاطِ چراغ‌ریسمانی، آژیرِ سرخ، اتاق کنترل با پروندهٔ Z زیر نور، فرار، کنار آتش، جدایی در سپیده‌دم، ایستگاه شمالی با پنجرهٔ برفی، ماشین با نقشهٔ داشبورد، اپیلوگ دره — با لنز اسکوپ، وینیِت، گرِین فیلم و کارت مکان/زمان.
- **ادبیات همه‌ی دیالوگ‌های پایانی بازنویسی شد:** ۳۹ کلیپ صدای تازه؛ هر صحنه حالا منطقِ روایی منسجم دارد (تحویل اسلحه → خوش‌آمد مریم → آژیر داخلی → پروندهٔ Z → فرار → اعتراف کنار آتش → جدایی → اعتراف سارا در ایستگاه) و **پایان دیگر طولانی نیست** — ریتم کوتاه و تند.
- **پلتفرمر به سبک سوپر ماریو بازسازی شد:** زمینِ چمن‌دار، بلوک‌های «؟» طلایی (کوبیدن از پایین = سکه)، آجرشکسته، لوله‌های سبز، سکه‌های چرخان، قلبِ اضافه‌جون، لگدکوبِ زامبی‌ها از بالا، کلاغ‌ها، پرش متغیر (نگه‌داشتن دکمه = بلندتر)، دویدن با دکمه، پرچم پایان با فانفار — در ۳ مرحله: خرابه‌های شهر / پل شکسته / راه شمالی.
- **صداهای پلتفرمر:** پرش، سکه، لگد، کوبیدن بلوک، شکستن آجر، آسیب، قلب، فانفار پرچم + صدای قدم.
- **سیو واقعی پلتفرمر:** چک‌پوینت وسط هر مرحله + سکه‌ها و جون‌ها بین مراحل ذخیره می‌شود (STORE)؛ مرگ = ادامه از چک‌پوینت؛ گیم‌اور = از اولِ همان مرحله با ۳ جون.
- **زامبی‌های صفحات داستان زمین‌گیر شدند:** دیگر «روی هوا» معلق نیستند — پا روی زمینِ خیابان، ردیف‌های عمق درست.
- **تیتراژ تازه:** خلاصه‌ی داستان + معرفی صداپیشگان + گویندگی «جادهٔ شمالی هنوز ادامه دارد...».

**نسخه‌ی ۴۲٫۰ — بازخورد جلسه‌ی ۴۲:**

- **دکمه‌های صفحه‌ی باخت تعمیر شد** — «تلاش دوباره» و «منوی اصلی» حالا واقعاً کار می‌کنند (ریشه‌ی باگ: بازسازی صفحه بعد از اتصال دکمه‌ها) + سیوِ خودکار پیش از هر شب تا «تلاش دوباره» همیشه جواب بدهد.
- **زامبی‌های منو و صفحات داستان بازطراحی شدند** — دیگر سایه‌ی سیاه نیستند: پوست فاسدِ رنگی، لباس پاره، دنده‌های بیرون‌زده، خونِ خشک، چشم سرخِ تابان و نورِ لبه‌ی ماه.
- **دستفروش مرموز کاملاً تازه شد** — موتور گفتگوی ضدتکرار با جفت‌های منسجم «سؤال آرش ↔ پاسخ فروشنده»؛ هر بازدید خط تازه؛ حذف همه‌ی «بیا ازم بخر»ها؛ متنِ دکمه‌ی خرید تمیز شد.
- **آیکون‌های کالاها از نو** — مجموعه SVG گرادیانی برای همه‌ی کالاهای کمیاب و نقشه‌های ساخت.
- **سرنخ‌ها حالا کاربرد واقعی دارند** — «شب‌نامه‌ی فردا» (ترکیب دقیق موج بعدی + پیشنهاد دفاعی) + پاداش‌های دائمی: ۳ سرنخ = +۱۰٪ سکه، ۶ = تخفیف دستفروش، ۱۰ = ترمیم شبانه‌ی برج، ۱۴ = +۶٪ دمیج. جست‌وجوی محیط و بازدیدهای دستفروش هم سرنخ می‌دهند.
- **منوی سازنده (تست)** — دکمه‌ی «سازنده» پایینِ منو: پرش مستقیم به هر فصل، شب آخر، مراحل پلتفرمر، سینمایی پایان + هدیه‌ی سازنده.
- **شکاف‌های صوتی بسته شد** — ۶۷ کلیپ تازه‌ی ElevenLabs؛ حالا همه‌ی ۲۱۲ خط دیالوگِ بازی صدای واقعی دارد (اینترو، انتقال فصل‌ها، پناهگاه، آژیر).
- **پایان جذاب‌تر** — بعد از تیتراژ، «صدایی از رادیوی خراب...» با صدای بم و مرموزِ Z: تیزرِ ادامه‌ی داستان.

**نسخه‌ی ۴۱٫۰ — صداهای جذاب‌تر و ضدتکرار + پایان سینمایی تازه:**

- **صداهای ElevenLabs بازتولید شد (۱۸۷ کلیپ):** متن‌ها کوتاه‌تر، طبیعی‌تر و «منطقی‌تر» شدند و مهم‌تر از همه، **دیگر هیچ جمله‌ای پشت‌سرهم تکرار نمی‌شود** — بارک شروع شب و بارک صبحِ ارشان هر بار از استخر سه‌گانه‌ی تازه انتخاب می‌شود.
- **دستفروش مرموز متنوع‌تر شد:** هر ۵ چهره، خوش‌آمد و پاسخِ تازه گرفت (۳ خط آغازین و ۳ پاسخ برای هر چهره) + دو شک تازه‌ی آرش.
- **پایان جدید:** بعد از صحنه‌ی جدایی، یک **اپیلوگ سینمایی شبانه** (جاده، ماه، ماشینِ در حال دور شدن + سه خط صدادار) و **تیتراژ پایانی اسکرولی** با معرفی کامل صداپیشگان — بعد صفحه‌ی «پایانِ فصلِ اول... ادامه دارد».

## داستان

همه‌چیز از یک بیماری ناشناخته شروع شد. **آرش** و **ارشان** ساختمان سه‌طبقه‌ی نیمه‌کاره را به پناهگاه تبدیل می‌کنند: «برج سه‌طبقه». ۳۶ شبِ دفاع در ۴ فصل — پناهگاه سه‌طبقه، مسیر مه‌آلود (عبور از کانال)، ایستگاه متروکه (برج مخابراتی) و آخرین پناهگاه (ملاقات **دکتر مریم**). پیام‌های ناقص بی‌سیم مسیر را نشان می‌دهند؛ پرونده‌ی «پروژه‌ی Z» همه‌چیز را عوض می‌کند و پایان داستان... به بازیکن بستگی دارد.

## ساخت از سورس

```bash
# ۱) HTML تکه‌فایل:
bash scripts/build_v43.sh            # → download/three-floors-to-survival.html

# ۲) APK اندروید (اول SDK را یک‌بار بسازید):
bash scripts/setup_sdk_213.sh        # یک‌بار: JDK + build-tools 34 + platform-34
bash scripts/build_apk.sh            # → download/three-floors-to-survival.apk

# ۳) تست‌های خودکار (۲۸ مورد):
bash scripts/test_v43.sh             # نیاز به agent-browser + سرور ۳۰۰۲ (scripts/serve28.py)
```

سورس بازی ماژول‌های `scripts/` است: پایه‌ی `base_v39.html` + داده‌های صوتی (`voices40/42/43_data.js`) + ماژول‌های منطق (`v40_module`، `v42_module` و چهار بخش `v43_*`) که اسکریپت ساخت، آن‌ها را به یک فایل می‌چسباند. صداهای تازه با `gen_voices43.mjs` و خط تولید ElevenLabs (متن + دم تزئینی → TTS → راستی‌آزمایی ASR → برش → نرمال‌سازی صدا) ساخته می‌شوند.
