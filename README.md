# سه طبقه تا مرگ (Three Floors to Death)

بازی ماجرایی–دفاعی فارسی برای مرورگر و اندروید — همه‌ی بازی در **یک فایل HTML** (بدون سرور، بدون وابستگی).

![نسخه](https://img.shields.io/badge/نسخه-۴۱٫۰-ffd873) ![سکو](https://img.shields.io/badge/سکو-Web%20%2B%20Android-4a7cc9)

## اجرا

| روش | فایل |
|------|------|
| اندروید (APK) — ساده‌ترین راه | [صفحه‌ی Releases](https://github.com/sahandmarami/three-floors-to-death/releases) → `three-floors-to-survival.apk` |
| مرورگر (کامپیوتر/گوشی) | `download/three-floors-to-survival.html` — بازش کنید، تمام |

**نسخه‌ی ۴۱٫۰ — صداهای جذاب‌تر و ضدتکرار + پایان سینمایی تازه:**

- **صداهای ElevenLabs بازتولید شد (۱۸۷ کلیپ):** متن‌ها کوتاه‌تر، طبیعی‌تر و «منطقی‌تر» شدند و مهم‌تر از همه، **دیگر هیچ جمله‌ای پشت‌سرهم تکرار نمی‌شود** — بارک شروع شب و بارک صبحِ ارشان هر بار از استخر سه‌گانه‌ی تازه انتخاب می‌شود.
- **دستفروش مرموز متنوع‌تر شد:** هر ۵ چهره، خوش‌آمد و پاسخِ تازه گرفت (۳ خط آغازین و ۳ پاسخ برای هر چهره) + دو شک تازه‌ی آرش.
- **پایان جدید:** بعد از صحنه‌ی جدایی، یک **اپیلوگ سینمایی شبانه** (جاده، ماه، ماشینِ در حال دور شدن + سه خط صدادار) و **تیتراژ پایانی اسکرولی** با معرفی کامل صداپیشگان — بعد صفحه‌ی «پایانِ فصلِ اول... ادامه دارد».

## داستان

همه‌چیز از یک بیماری ناشناخته شروع شد. **آرش** و **ارشان** ساختمان سه‌طبقه‌ی نیمه‌کاره را به پناهگاه تبدیل می‌کنند: «برج سه‌طبقه». ۳۶ شبِ دفاع در ۴ فصل — پناهگاه سه‌طبقه، مسیر مه‌آلود (عبور از کانال)، ایستگاه متروکه (برج مخابراتی) و آخرین پناهگاه (ملاقات **دکتر مریم**). پیام‌های ناقص بی‌سیم مسیر را نشان می‌دهند؛ پرونده‌ی «پروژه‌ی Z» همه‌چیز را عوض می‌کند و پایان داستان... به بازیکن بستگی دارد.

## ساخت از سورس

```bash
# ۱) HTML تکه‌فایل:
bash scripts/build_v40.sh            # → download/three-floors-to-survival.html

# ۲) APK اندروید (اول SDK را یک‌بار بسازید):
bash scripts/setup_sdk_213.sh        # یک‌بار: JDK + build-tools 34 + platform-34
bash scripts/build_apk.sh            # → download/three-floors-to-survival.apk

# ۳) تست‌های خودکار (۴۰ مورد):
bash scripts/test_v40.sh             # نیاز به agent-browser + سرور ۳۰۰۲ (scripts/serve28.py)
```

سورس بازی ماژول‌های `scripts/` است: پایه‌ی `base_v39.html` + `voices40_data.js` (داده‌ی صوتی) + `v40_module.js` (منطق‌های ۴۰/۴۱) که اسکریپت ساخت، آن‌ها را به یک فایل می‌چسباند. صداهای تازه با `gen_voices40extra.mjs` و خط تولید ElevenLabs (متن + دم تزئینی → TTS → راستی‌آزمایی ASR → برش → نرمال‌سازی صدا) ساخته می‌شوند.

## ساختار مخزن

```
android/                        پوسته‌ی اندرویدی WebView (بدون گرادل — aapt2/d8 مستقیم)
download/                       خروجی‌ها: HTML + APK امضاشده
scripts/base_v39.html           پایه‌ی بازی (تک‌فایل)
scripts/voices40_data.js        داده‌ی کلیپ‌های صوتی (base64)
scripts/v40_module.js           منطق‌های نسخهٔ ۴۰/۴۱ (شخصیت‌ها، دستفروش، پایان، ضدتکرار)
scripts/build_v40.sh            اسکریپت ساخت HTML
scripts/build_apk.sh            اسکریپت ساخت APK
scripts/test_v40.sh             ۴۰ تست خودکار
scripts/gen_voices40extra.mjs   خط تولید صدای ElevenLabs
scripts/ttb.keystore            کلید امضای APK
```

> کلید‌های API داخل مخزن با خواستِ صاحبِ پروژه باقی مانده‌اند.
